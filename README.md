📊 KPI Dashboard Using Microsoft Excel

📌 Project Overview
The KPI Dashboard is an Excel-based data visualisation project designed to monitor key performance indicators and analyse business performance through an interactive dashboard.
It helps users understand important business metrics and explore performance across different years, regions, and product categories.

✨ Features
📈 KPI tracking and performance monitoring
🌍 Region-wise performance analysis
📅 Year-wise data analysis
🛍️ Category-wise performance comparison
📊 Interactive charts and visualisations
🎯 Data-driven insights for business decisions
🛠️ Tools & Technologies

Microsoft Excel
Excel formulas and functions
Charts and data visualisation
Data cleaning and analysis
Key Performance Indicator (KPI) analysis

🚀 How to Use
Download or clone this repository.
Open KPI_Dashboard.xlsx in Microsoft Excel.
Navigate to the dashboard worksheet.
Use the available year, region, and category filters.
Explore the KPIs and charts to analyse business performance.

🎯 Project Objectives
Present business metrics in a clear visual format.
Simplify performance monitoring.
Compare results across different business dimensions.
Support informed, data-driven decision-making.
